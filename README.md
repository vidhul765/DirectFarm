# DirectFarm 🌾

A web-based Farmer-to-Customer marketplace that allows farmers to list products directly and customers to view them.

## Features
- User Login & Registration
- Add Products with Images
- View Products
- Delete Products

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite

## Purpose
To reduce middlemen and improve transparency between farmers and customers.
